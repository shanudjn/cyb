# MIT OpenCourseWare cybersecurity research library

Research snapshot: 2026-10-11

This directory indexes official MIT OpenCourseWare materials relevant to the
seven-day cybersecurity course in the parent directory. It contains original
summaries, a one-week reading map, and links to the authoritative OCW pages.

It intentionally does not mirror or republish the full OCW corpus. MIT OCW
offers official downloadable course packages from each course's **Download
Course** page. Use those packages when you need offline copies so that course
structure, attribution, licenses, and updates remain intact.

Open `index.html` for the visual library or `sources.json` for the machine-
readable research manifest. The parent course's **MIT lecture studio** adds
seven guided lectures, 35 timestamped chapter links, original teaching notes,
worked examples, exercises and model answers. Its curriculum is stored in
`../mit-lecture-data.js`.

## Core corpus

- 6.858 Computer Systems Security, Fall 2014
- 6.5660 Computer Systems Security, Spring 2024
- 6.857 Network and Computer Security, Spring 2014
- 6.033 Computer System Engineering, Spring 2018 — security section
- 6.1200J Mathematics for Computer Science, Spring 2024 — cryptography lecture

- 6.829 Computer Networks, Fall 2002

All linked MIT materials remain subject to the license and terms shown by MIT
OpenCourseWare. The Packet & Proof summaries and schedules are original course
material and are not an MIT course, credential, or endorsement.
